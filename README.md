# Змейка: Сокровищница

Домашнее задание №1 по дисциплине «Алгоритмизация и программирование» (ИУ5, МГТУ им. Н.Э. Баумана).

Проект содержит базовую консольную игру «Змейка» и индивидуальный вариант №25 «Сокровищница» на C++17. Игровая логика отделена от консольного интерфейса, покрыта модульными тестами GoogleTest, документирована Doxygen и собирается в Docker-контейнер.

## Правила

### Базовая игра

- Поле 10 × 10, змейка стартует в центре и имеет длину 1.
- Еда появляется в случайной свободной клетке. Съеденная еда даёт +1 очко и увеличивает длину змейки на 1.
- Управление — W/A/S/D или стрелки.
- Столкновение со стеной или хвостом завершает игру поражением. В конце выводится счёт.
- Клавиша H открывает справку, Q завершает игру.

### Вариант 25 «Сокровищница»

На поле дополнительно находятся пять закрытых сундуков. Только в одном из них лежит золото:

- пустой сундук: −1 очко, игра продолжается;
- сундук с золотом: +10 очков и немедленная победа.

Содержимое сундука скрыто до момента открытия, поэтому игрок сам выбирает порядок исследования поля. Обычная еда, рост змейки и столкновения работают по базовым правилам.

## Сборка

Требования: компилятор с поддержкой C++17, CMake 3.20+, Git (для загрузки GoogleTest через FetchContent).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 4
```

Проект собирается с флагами `-Wall -Wextra -Wpedantic -Werror`.

## Запуск

```bash
./build/snake_game                 # вариант 25 (по умолчанию)
./build/snake_game --base          # базовая игра без сундуков
./build/snake_game --demo          # автоматическая демонстрация
./build/snake_game --demo --seed 25 --max-turns 120
./build/snake_game --help          # справка и правила
```

В интерактивном режиме перед началом выводятся правила. Во время игры справка вызывается клавишей H; игра при этом приостанавливается.

### Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--base` | базовая игра без сундуков |
| `--demo` | автоматическая демонстрация без ввода |
| `--seed N` | детерминированное расположение объектов |
| `--max-turns N` | лимит ходов демонстрации |
| `--delay MS` | задержка между ходами демонстрации |
| `--quiet` | только итог демонстрации |
| `--no-color` | отключить ANSI-цвета |
| `--help` | справка и правила |
| `--version` | версия программы |

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

Тесты проверяют начальное состояние, уникальность объектов, детерминированность генератора, движение, запрет разворота, рост от еды, пустой и золотой сундуки, повторное открытие, столкновения со стеной и хвостом, остановку после победы и сброс игры. Всего 16 модульных тестов; дополнительно CTest запускает smoke-тест демонстрации и проверку справки.

## Docker

```bash
docker build -t snake-treasure .
docker run --rm snake-treasure
docker run --rm snake-treasure --demo --seed 25 --max-turns 120 --quiet
docker run --rm -it snake-treasure --seed 25
```

По умолчанию контейнер запускает демонстрацию. Для интерактивной игры нужен флаг `-it`, чтобы контейнер получил TTY, и аргументы, перекрывающие демонстрационный CMD.

## Решения по архитектуре

- **Логика отделена от ввода-вывода.** Класс `snake::Game` не знает о терминале, поэтому правила можно тестировать без эмуляции клавиатуры.
- **Детерминированный генератор.** Конструктор `Game(unsigned seed)` и параметр `--seed` позволяют воспроизводить расположение сундуков, еды и результаты демонстрации.
- **Восстановление состояния.** `Game::from_state` используется тестами для проверки столкновения с хвостом и других редких сценариев; метод также подходит для будущего сохранения игры.
- **Два режима.** `--base` демонстрирует базовую игру, режим по умолчанию включает вариант 25.
- **Пошаговое управление.** Один шаг выполняется по нажатию клавиши. Это делает игру предсказуемой в консоли и позволяет спокойно читать справку.
- **Безопасный ввод.** В Linux/WSL терминал переводится в неканонический режим RAII-объектом `RawMode`, а при выходе настройки восстанавливаются.

2. `docker`: сборка образа и запуск демонстрации в контейнере.
